NUNES AI CRM V2.10.0 - READ ME FIRST

MAIN SERVER COMPUTER
1. Run 1_SETUP_MAIN_CRM_SERVER.bat
2. Run SETUP_FIREWALL.bat once as Administrator when office PCs connect over LAN.
3. Use the desktop icon NUNES AI CRM - SERVER. This is a server console, not the owner sales dashboard.

OWNER COMPUTER
1. On the server, run SHOW_OWNER_SETUP_CODE.bat. V2.10.0 starts/repairs the latest server automatically and shows the code immediately.
2. On the owner PC, run SETUP_OWNER_PC.bat and enter that code.
3. After setup use NUNES AI CRM - OWNER.
4. Owner sees overall company performance and all 10 staff.

10 STAFF COMPUTERS
1. Run 2_SETUP_STAFF_PC.bat once.
2. Choose the correct staff profile.
3. After setup use NUNES AI CRM - Staff Name.
4. Each staff member sees only their assigned work. Team race is shared live.

WHATSAPP / GMAIL
Each owner/staff computer signs into its own WhatsApp and Gmail once. Accounts are not shared.

FAST SETUP
Staff/owner PCs do not install Node.js, npm, SQLite or the CRM database. They only receive a small desktop launcher.
