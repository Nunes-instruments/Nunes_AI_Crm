NUNES AI CRM - GITHUB TEST -> PRODUCTION UPDATE FLOW
====================================================
Repository: https://github.com/Nunes-instruments/Nunes_AI_Crm.git
Testing branch: testing
Production branch: main

SAFE RELEASE FLOW
-----------------
Current source changes
  -> GITHUB_TEST_AND_RELEASE.bat
  -> push sanitized source to `testing`
  -> clone exact testing commit back from GitHub
  -> JavaScript syntax validation
  -> isolated CRM startup with fresh temporary database
  -> /api/health and homepage smoke test
  -> GitHub Actions validation on testing
  -> exact tested commit fast-forwarded to `main`
  -> MAIN SERVER checks/downloads production main
  -> automatic SQLite pre-update backup
  -> application code replaced; live data/settings preserved
  -> server restarts
  -> Owner + Staff web clients detect new version and reload

PRODUCTION main SHOULD NOT BE USED AS THE DEVELOPMENT BRANCH.
Use `testing` first for every normal bug fix or feature change.

DATA NEVER PUBLISHED
--------------------
.env
SQLite databases / WAL / SHM
data/company-crm.json and company-crm-key.txt
OAuth / Gmail / Google Drive token files
staff-server runtime config
logs / pids / temporary files
backups
staff photos/runtime private files

MAIN SERVER DATA SAFETY
-----------------------
The installed server keeps its existing data/, logs/, backups/ and .env.
Before an application-code update, the install process makes a consistent
pre-update SQLite backup. A failed safety backup stops the update.
