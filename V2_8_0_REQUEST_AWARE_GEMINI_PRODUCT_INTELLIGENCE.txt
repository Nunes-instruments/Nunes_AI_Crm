- Gemini product grounding is enabled by default for better exact-product research.
- Added current Gemini model fallback chain and clearer authentication/model/rate-limit errors.
- CONFIGURE_PRODUCT_INTELLIGENCE.bat now saves and live-tests the key.
- Added TEST_GEMINI_CONNECTION.bat.
- API key is not bundled in the updated ZIP; run CONFIGURE_PRODUCT_INTELLIGENCE.bat once and paste a Google AI Studio Gemini API key.
